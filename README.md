# ぷらんと日記

スマホで遊べる、のんびり3D植物育成ゲーム。ブラウザだけで動き、サーバーは使いません。

## 遊び方
`index.html` をブラウザで開くだけです。(インターネット接続が必要です。3D表示ライブラリ three.js を CDN から読み込みます)
GitHub Pages で公開する場合は、Settings → Pages で `main` ブランチのルートを選びます。

## 特徴
- 植物26種、9段階の成長、遺伝によるかけあわせ
- 5つの場所(窓辺・ベランダ・庭/畑・温室・水槽)
- 季節・天気・昼夜、図鑑、依頼、庭のランク
- セーブはブラウザの localStorage のみ(個人情報は送信しません)
- 「こうかん」はコードを見せ合う方式(サーバー不使用)

## 構成
`js/data.js` データ / `sim.js` ゲームのルール / `plants3d.js` 植物の3D / `places.js` 場所の3D / `world.js` 3D空間 / `audio.js` 音 / `ui.js`・`sheets.js` 画面 / `main.js` 起動

## 権利・ライセンス
- 絵(3Dモデル)・音・文章・データは、このゲームのためにすべて自作しています。外部の素材は使っていません。
- 3D表示に [three.js](https://threejs.org/)(MIT License)を使用しています。
- 植物の説明はゲーム用の表現です。実在の植物の効能・食用・毒性・安全性を示すものではありません。
- 実在のゲーム・キャラクター・名称・ロゴ・UIの模倣はしていません。

## 感想・不具合
メニューの「感想・不具合」から、チェックと自由記入で書くと、文章にまとめられます。コピーや共有ボタンで、作者(GitHubのIssueなど)やSNSに送れます。サーバーへの自動送信はしていません。
